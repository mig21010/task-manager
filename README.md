# AI Task Management Agent

An intelligent task management system 
powered by Claude AI with RAG capabilities,
semantic search, and multi-step tool calling.

## 🚀 Features
- Natural language task management
- Semantic search with RAG (Pinecone)
- Multi-step tool chaining
- Conversational memory
- Function calling with Claude API

## 🛠️ Tech Stack
**Backend:** .NET 8, ASP.NET Core, 
            EF Core, SQL Server
**Frontend:** React, TypeScript, 
             Vite, Tailwind CSS
**AI:** Claude API (Anthropic)
**RAG:** Pinecone + OpenAI Embeddings

## ⚙️ Setup
1. Clone the repository
2. Configure appsettings.json
3. Run migrations
4. Start the API
5. Start React frontend

## 🔧 Environment Variables

OPENAI_API_KEY=
PINECONE_API_KEY=
